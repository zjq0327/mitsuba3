# 2022 织物正向模型：下一步实施计划

更新：2026-09-27。当前为设计计划，论文 BRDF 尚未实现。

## 目标与当前状态

目标是先实现 Jin 等人的 **Woven Fabric Capture from a Single Photo（2022）** 正向模型，得到可追溯、可重复的平纹平面与圆筒反射结果。第一版称为“2022 确定性正向参考实现”，不把无噪声平纹子集称作整篇论文完整复现。

已完成的环境准备：

- 本地 Mitsuba 源码 `fd9c9ceb38deb511a5c3f8479c8b14c0b552167e`，版本 `3.10.0.dev1`，Dr.Jit `1.6.0.dev1`。
- 源码 Release 构建、CPU/CUDA Cornell Box 渲染、Python 自定义材质对照通过；官方 diffuse 测试 3 项通过。
- RTX 5070 可使用 `cuda_ad_rgb`。`scalar_rgb` 可用于核查；`llvm_ad_rgb` 尚缺 LLVM 运行库。
- 入口为 [validation/README.md](validation/README.md)，复跑入口为 `validation/run.cmd`。

本轮固定版本，不以升级依赖或更换渲染器作为前置工作。用户之前的丝袜实验保留，不作为这次论文复现的输入、调参目标或基准。

## 第一版的范围

第一版包含单层 SGGX 方向反射、双法线漫反射、一种 2×2 平纹、解析弯曲纱线属性、点光直接照明，以及分项验证。

固定光学厚度 `tau = T*rho = 2`；经纬纱可具有各自的粗糙度与颜色。第一检查点使用零扭转、关闭随机扰动，显式设置高光乘数 `Us=1`、法线扰动 `Un=1`。单独将 `Q=0` 不能代替关闭高光随机数。

2022 本身不提供纱线间空隙和透射；这些属于后续 2023 阶段。照片反求、FabricNet、针织线圈、人物丝袜、Cycles 移植、全纤维几何和复杂间接光验证均在此里程碑之后。

## M1：固定数学定义并实现单点参考

输入统一为指向表面外侧的光方向 `light_dir`、视方向 `view_dir`、宏观法线 `nm`、纱线法线 `n`、纤维方向 `t`。所有方向归一化，`n·t=0`。必须分别保存原始 BRDF 和乘入射余弦后的直接照明因子，避免接口混用。

按正文 §3.2 和补充 Eq.(1)–(4) 实现：

- SGGX：`S = I + (alpha^2 - 1) * t*t^T`；特殊轴沿纤维方向，而不是纱线法线。
- `sigma(w) = sqrt(w^T S w)`。
- `D(h) = 1 / (pi * alpha * (h^T S^-1 h)^2)`。
- 方向项使用论文单层衰减与 `tau=2`。不替换为 Smith GGX、不额外加入 Fresnel。
- 漫反射使用正文 Eq.(1)：`fd = kd/pi * [w * <light·nm>/<light·n> + (1-w)]`。`w=1` 对应宏观法线，`w=0` 对应纱线法线。

数值实现优先使用 `expm1` 等代数等价稳定形式。有效域、零向量、背面和掠射情况单独列清，不用任意亮度钳制掩盖问题。直接照明下的漫反射因子可先整理为 `kd/pi * [w*<light·nm> + (1-w)*<light·n>]`，同时记录其有效域与边界处理。

补充材料的层法线约定、布面和纱线余弦的关系，在 `references/2022_conventions.md` 固定后再接插件。保留公式编号与任何推导假设。

M1 验收：

- `alpha=1` 时 `D=1/pi`、`sigma=1`；纤维轴反向不改变 SGGX。
- 整体旋转方向、法线和纤维轴后结果保持不变。
- 用独立深度积分 `integral_0^tau exp[-s*(Lambda_i+Lambda_o)] ds` 核对闭式 G。
- 用球面积分 `0.5 * integral |w·m| D(m) dm` 核对 `sigma(w)`；逐步加密积分确认收敛。
- 仅对固定局部配置的方向反射项检查互易性。论文漫反射近似明确不互易，不要求完整模型通过互易性测试。

提出的数值门槛：常规角度下 float64 代数/旋转检查采用约 `1e-10` 的混合绝对与相对误差；深度积分目标相对误差 `1e-6`；SGGX 投影积分目标相对误差 `1e-3`。这些是验收目标，不是现有结果。低粗糙度、掠射角单列加密积分结果，禁止为了过门槛修改论文公式。

## M2：Mitsuba 插件与独立直接照明对照

先接均匀纱线方向，不引入织纹。以 `cuda_ad_rgb` 实现求值、采样和 PDF，并用单点参考验证。

需要特别处理方向约定：论文的入射方向是朝向光源的方向，而在相机路径命中点，Mitsuba `si.wi` 指向之前的相机路径顶点，待评估的 `wo` 指向下一段/光源。Mitsuba `eval()` 还包含其规定的余弦权重。2022 漫反射不互易，不能依赖交换方向后结果相同。

因此先写明 Radiance 传输模式下的参数映射和测度转换，确保 NumPy 直接照明结果与插件输出一致。宏观法线与纱线法线必须都能访问，不把其中一个直接覆盖后丢失另一个。Importance 模式的处理单独定义；第一版不宣称双向路径追踪兼容。

首版采样可使用覆盖有效反射域的简单分布（如合适局部坐标中的余弦半球采样），以无偏且与 PDF 一致为先。它可能对尖锐高光效率较低，需要记录噪声与收敛，后续再实现更合适的重要性采样。

M2 验收：

- 同一方向对、参数、有效域下，CPU 双精度参考与 GPU 插件的余弦加权值一致；先以 `atol=1e-6, rtol=1e-4` 检查常规样本，高动态范围与掠射样本单独分析。
- 抽样得到的方向满足支持域，返回 PDF 与独立 `pdf()` 一致；`sample_weight*pdf` 与 `eval()` 一致。
- 分别关闭方向项/漫反射项，核对点光下平面中心像素；同时改变距离检查光照平方反比，防止把灯光错误当作材质错误。
- 保存原始线性数据和差值，不在 sRGB PNG 上做公式精度判断。

## M3：无噪声平纹与圆筒

程序化生成一个 2×2 平纹重复单元，给出可见经纬纱归属、纱线段 ID、法线和纤维方向。弯曲圆/椭圆柱的参数化参考正文 §3.1 及其引用的 Irawan–Marschner 2012；2022 未写全的实现细节必须另列推导，不能凭图像猜测后称为作者原实现。

先实现圆弧子集并说明限制；使用正的高度缩放 beta。修改法线时同步修改纤维方向并重新归一化，特别检查补充 Eq.(8) 的平顶/零分母情况。法线用参数曲面的有限差分独立复核。

两个场景使用相同材质参数：

1. 平面：检查单元交错、经纬归属、周期拼接、法线与方向。
2. 圆筒：检查宏观坐标变换、连续角度变化与高光宽度/位置。使用圆筒弧长定义织纹尺度，避免相机距离改变织纹密度。

先用经纬两色作调试，再用统一灰色观察高光。输出 diffuse-only、directional-only、combined、normal、fiber-direction 和 yarn-ID 图。纱线属性是表面着色输入；不自动产生真实微观位移或轮廓。

采用明确记录的像素超采样，并先逐样本求值再平均；不直接平均法线后假装得到正确过滤。2023 的足迹积分不在此处提前混入。

## M4：集中验收并交付首版

固定相机、点光强度、背景、曝光和显示转换；每次只变化一个材质参数，保存完整 JSON 与随机种子。

需要的对照：

- 粗糙度三档、纤维方向旋转 90°。
- 漫反射混合权重 `w=0/0.5/1`。
- 高度缩放 beta 的平坦/中等/明显起伏。
- 经纬纱不同颜色与相同颜色。
- 至少三档像素采样，核对高光和平均亮度收敛。

能量积分记录作为诊断，不把两个独立颜色参数的任意组合都强制解释为守恒材料。若论文近似本身有偏差，应区分模型限制与实现错误。

首版完成条件：

- 一条命令生成平面、圆筒、分项/调试图、参数记录和验证报告。
- 数值验收通过或有具体、可复核的边界说明，无未解释的常规角度失败。
- 实际查看整体图和织纹局部，确认方向、高光、拼接和缩小行为符合模型预期。
- 分开写明“公式一致性”“Mitsuba 接口一致性”“论文现象定性一致性”；没有作者样本参数和原始线性图片时，不报告虚假的逐像素论文复现精度。

## 首版之后

按顺序加入纤维扭转、绑定纱线段的高光随机项、法线随机扰动和更多织纹。每项保留开关，使用相同参数做前后对照。随机项的分布与均值按补充 Eq.(5)–(8) 检查，不能随相机移动重新抽样。

在 2022 核心与这些扩展验证后，保留它作为固定基准，再建立独立的 2023 模型；届时再处理正反面、空隙直通、纱线透射、可见性和像素足迹。两篇共享基础数学工具，但保留独立参数定义与公式。
